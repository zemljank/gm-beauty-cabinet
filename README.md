# GM Beauty Cabinet

Каталог уходовой косметики и космецевтики с акцентом на премиальную подачу, фильтрацию и удобное пополнение из прайса.

- Live demo: [gm-beauty-cabinet.vercel.app](https://gm-beauty-cabinet.vercel.app)
- Репозиторий: [github.com/zemljank/gm-beauty-cabinet](https://github.com/zemljank/gm-beauty-cabinet)

## Что уже есть

- главная страница с hero, категориями и блоком `Выбор врача`;
- отдельный каталог с поиском, фильтрами и сортировкой;
- карточка товара, корзина и раздел `Избранное`;
- локальные фотографии товаров и баннеров;
- структура данных, которую можно расширять без правки интерфейса.

## Запуск

```bash
npm install
npm run dev
```

## Проверка

```bash
npm run build
npm run lint
```

## Где добавлять товары

Все позиции лежат в файле:

`src/data/products.ts`

Чтобы добавить новый товар, нужно добавить новый объект в массив `products`:

```ts
{
  id: "unique-id",
  brand: "ANGIOPHARM",
  country: "Россия",
  name: "Название продукта",
  price: 2500,
  volume: "50 ml",
  category: "cream",
  concern: ["увлажнение", "чувствительная кожа"],
  shortDescription: "Короткое описание для карточки.",
  accent: "#e9dfd7"
}
```

## Что дальше

Для дальнейшего расширения каталога нужны актуальный прайс и подтверждённые описания новых позиций. Подключение отправки заказов и учёта остатков — отдельный этап.

## Наполнение и адаптивность

- На главной доступны все 8 категорий, 6 подборок по потребностям кожи, 4 бренда и ответы на вопросы о заказе.
- Раздел `#help` объясняет работу каталога; подвал доступен на каждой странице.
- В корзине можно подготовить и скопировать список для администратора. Сайт не отправляет заказ автоматически; наличие, оплату и получение подтверждает клиника.
- Поиск доступен над каталогом на всех устройствах. На экранах до 1023 px фильтры открываются в отдельной панели с кнопкой показа результатов.
- `src/styles/storefront.css` задаёт общие отступы, размеры элементов управления и адаптивные правила поверх исходных стилей. Узкие карточки перестраивают кнопки через container queries.
- Товары, цены и фотографии остаются в `src/data/products.ts`; тексты подборок — в `src/data/storefront.ts`.

При изменении интерфейса проверяйте ширины 320, 390, 600, 768, 1024 и 1440 px: главную, каталог, карточку товара, пустые/заполненные избранное и корзину, помощь, поиск без результатов и панель фильтров. Для проверки корзины добавьте товар, измените количество и откройте список для администратора.
